# CSVデータ管理

このフォルダには、地図に表示するレイヤー設定と地点データを置きます。

公開画面は神山町版として設定されています。`layers.csv` から参照されている `kamiyama-` 付きCSVと `child-safety.csv` が公開対象です。その他のCSVは、元となった岡本地区版の参考データとして残しています。

## ファイル構成

- `layers.csv`: レイヤー名、地点CSV、アイコンの対応表
- `locations/`: レイヤーごとの地点データ
- `templates/location-template.csv`: 新しい地点CSVを作るときのひな形

## 地点データの必須項目

地点の座標は、次のどちらかで指定します。

- `Geo3x3`
- `lat` と `lng`

上記以外の列は、地点を選択したときの詳細情報として表示されます。

新しいレイヤーを追加するときは、`locations` にCSVを追加し、`layers.csv`にも1行追加してください。

## 子ども注意ポイント

`locations/child-safety.csv` には、ヒアリングで確認した次のような場所を記録します。

- 車・自転車が多い道: `🚗`
- 見通しの悪い交差点: `👀`
- 暗い道、人通りの少ない場所: `🌙`
- 水路、川、池、崖など: `🌊`
- 飛び出しに注意する場所: `🏃`

`emoji` 列に絵文字を入れると、その地点のマーカーとして表示されます。公開前に、`公開可否` と `確認状況` を必ず確認してください。
